# «Тише» — сайт студии массажа в Гомеле

Рабочий первый вариант по согласованному направлению. Next.js 16.4.2, React, TypeScript, обычный CSS. Код сайта — `site/`. Рабочее название можно заменить в `site/lib/site.ts`, шапке и подвале; фактические контакты и цены пока не получены.

## Запуск

Требуется Node.js 24 (проверено на 24.19.0).

```sh
cd site
npm_config_cache=/workspace/.npm-cache npm ci
npm run dev -- --hostname 0.0.0.0
```

Если `.env.local` отсутствует, скопируйте `.env.example` в `.env.local`. Файл с реальными значениями игнорируется Git. Не вставляйте секреты в переписку, код или публичные переменные.

Для производственной версии: `npm run build`, затем `npm run start -- --hostname 0.0.0.0`. Сборка и процессы не заменяют публикацию. Применение новых значений `SITE_URL` требует повторной сборки; после изменения остальных переменных перезапустите процесс.

## Проверки

```sh
cd site
npm run lint
npm test
npm run build
# В другом терминале запустить production-сервер:
npm run start -- --hostname 0.0.0.0 --port 3001
# Затем:
TEST_BASE_URL=http://127.0.0.1:3001 npm run test:smoke
```

Smoke-проверка использует Chromium `/usr/bin/chromium` (либо `CHROMIUM_PATH`). Она предназначена для окружения с `LEADS_ENABLED=false`: в базу и Telegram ничего не отправляет. Проверяет четыре размера экрана, меню, подстановку направления, FAQ, отсутствие переполнения, загрузку изображения/шрифта, серверный HTML, метаданные и ошибки API. Результаты — `content/previews/`.

Семь модульных тестов проверяют валидацию, согласие, повторы, сохранение и независимость результата от сбоя Telegram. Это проверки с тестовыми адаптерами; они не подтверждают доступ к реальным сервисам.

## Реальные заявки

1. В своём Supabase выполните `supabase/leads.sql` через SQL Editor. RLS включён, анонимный доступ закрыт.
2. В `site/.env.local` задайте `SUPABASE_URL` и `SUPABASE_SECRET_KEY`. Секретный ключ используется только на сервере.
3. Создайте бота у @BotFather, нажмите Start у нового бота. Добавьте `TELEGRAM_BOT_TOKEN`. Команда `npm run telegram:chat-id` выводит только ID найденных чатов; запишите нужный в `TELEGRAM_CHAT_ID`.
4. Дополните и проверьте `site/app/privacy/page.tsx`: юридический оператор, контакт, сроки хранения, доступ к данным, условия работы Supabase/Telegram и передачи данных. Заполните `PRIVACY_OPERATOR` и `PRIVACY_CONTACT`.
5. Только после подготовки установите `LEADS_ENABLED=true`, перезапустите сайт и проведите одну реальную тестовую заявку. Проверьте строку в Supabase и уведомление в Telegram.

Пока настройка не завершена, кнопка отправки отключена, а API отвечает 503. Заявка не подтверждает время визита. Сохраняем заявку в Supabase до отправки Telegram; при сбое уведомления запись остаётся в базе с `telegram_notified=false`. Такие записи нужно отслеживать в Table Editor и при необходимости обрабатывать вручную. Повтор с тем же request_id не создаёт новую запись/уведомление. Автоматическая очередь повторов Telegram пока не реализована.

Ограничение частоты — в памяти одного процесса (5 корректных запросов на IP за 15 минут). Для нескольких инстансов используйте общий rate limiter/правила платформы; на собственном сервере доверяйте X-Forwarded-For только от своего прокси. База остаётся главным хранилищем заявок.

## Перед публикацией

`SITE_URL` должен содержать реальный HTTPS-домен. Без него главная помечена noindex, sitemap пуст, canonical отсутствует; Next.js использует локальный адрес для автоматической OG-ссылки. Это ожидается в текущем черновике и должно быть исправлено заданием домена и повторной сборкой перед публикацией. Затем проверить canonical, sitemap, OG и JSON-LD на реальном адресе.

Подтверждённых данных об операторе, адресе, часах, ценах, специалистах и отзывах нет — они не выдуманы. JSON-LD содержит реальные видимые FAQ; сущность LocalBusiness добавляется после подтверждения бренда и контактов. `llms.txt` пока описывает статус концепции, его нужно актуализировать перед запуском.

Публикация не выполнялась. Для импорта на Vercel корневая папка проекта — `site`; переменные задаются там же до сборки. Для коммерческого использования потребуется подходящий тариф (Vercel Pro) либо другой хостинг.
