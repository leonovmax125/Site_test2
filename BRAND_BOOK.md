# «Тише» — первый вариант

Рабочее название предложено агентом после разрешения пользователя разработать концепцию; реальный бренд ещё нужно подтвердить.

- Текст: #243f35. Главная кнопка: #254c3b. Контрастная секция: #183b2c. Фон: #fafbf7. Светло-зелёная форма: #dfe8d8.
- Manrope Variable 200–800, используется 400/500/600. Поддерживает кириллицу, подключён через next/font/local; лицензия OFL в site/app/fonts/.
- Первый экран: крупный рубленый заголовок, справа короткое приглашение, ниже широкая предметная фотография. Меню короткое; основное действие — оставить заявку.
- Услуги — разделённые линиями строки с собственными графическими символами. Последовательность записи — три шага. FAQ — доступные раскрывающиеся details. Форма — светлая панель на зелёном фоне.
- Предметная фотография с эвкалиптом, камнем, белым льном и маслом — собственная генерация, служит только настроению. Не использовать её как подтверждение реального интерьера/инвентаря.
- Мягкие изменения цвета кнопок, небольшой сдвиг основной кнопки при наведении; без автопрокрутки, тяжёлых анимаций и параллакса. Reduced motion отключает движение и плавный скролл.
- Минимум формы: имя, телефон, направление по желанию и отдельное согласие. Не показывать отправку успешной без сохранения в реальную базу.
